# Rules
Format: Rule #.# (ex. Rule 1.2)
1. Hacks
	1. Fullbright is allowed
	2. The following is prohibited unless given permission by moderators
		1. Xray
		2. Flying is not allowed except by moderators in spectator mode
		3. Spectator should not be abused to xray or fly
		4. Aimbot (applies for both melee attacks and projectile attacks)
		5. Wall climbing (defined as being in a flying state while next to a wall, as if you are climbing that wall)
		6. Automatic totems
		7. Automatic killing (using external software to automatically kill any mobs or players)
		8. Autoclickers are not allowed except for farms and loading chunks
		9. Hacking into the console
    	10. Using the creative inventory while in survival
    	11. Macros (defined as programmed keybinds or similar things that can cause unfair gameplay with pre-programmed external tools) are not allowed.
    3. Any hacks not mentioned are not allowed unless specifically allowed by a mod or admin. Use your own judgement.
2. Abuse (includes corrupt behavior)
	1. Moderator ability abuse is not allowed
	2. Role or name abuse is not allowed
	3. Impersonation is not allowed
	4. Using glitches that are not widely considered features is not allowed
3. Chat/Voice Chat
	1. Don't spam
	2. Talking about explicit content is not allowed unless it is a acceptable joke
	3. Using this server as a tool for breaking real life law (outside of the video game or discord or in some cases the website) is not allowed.
	4. Excessively advertising or promoting other servers is not allowed
	5. Any sort of child predation is not allowed
 	6. Be nice. 
4. General
    1. Botting is not allowed
    2. Refrain from destroying others' builds (I'm looking at you, YeeVool)
    3. Just don't be stupid, stupid.
